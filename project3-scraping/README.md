# Project 3 — Web Scraping (вуз-партнёры и олимпиады)

Проект 3 — часть финального веб‑сервиса администратора профильной школы.  
Задача скрапера — непрерывно собирать данные о вузах‑партнёрах и олимпиадах, которые дают льготы при поступлении по направлениям химии, биологии, биотеха, медицины, биомедицины, биоинформатики и компьютерных наук.

## Что делает скрапер

1. **Вузы и направления**
   - Парсит целевые вузы (СПб и Москва + НГУ).
   - Фильтрует только нужные направления: химия, биология, биотехнология, медицина, биомедицина, биоинформатика, компьютерные науки и т.п.
   - Собирает:
     - минимальные проходные баллы ЕГЭ;
     - средний балл поступивших (где есть);
     - количество бюджетных мест;
     - стоимость обучения (руб/год);
     - список предметов ЕГЭ для поступления;
     - информацию об индивидуальных достижениях (ИД).

2. **Олимпиады и льготы**
   - Парсит целевые олимпиады (химия, биология, информатика, математика, биоинформатика и смежные).
   - Для каждого вуза из списка собирает:
     - за какие олимпиады дают **БВИ**, 100 баллов или дополнительные баллы;
     - по каким предметам / профильным направлениям;
     - текстовое описание льгот.

3. **Непрерывность**
   - При каждом запуске дописывает в CSV новую порцию данных с временной меткой.
   - Есть планировщик (`scheduler/runner.py`), который запускает скрапер регулярно (по умолчанию каждые 6 часов).

4. **Интеграция с финальным проектом**
   - Актуальные данные агрегируются в `data/partners.json`.
   - Этот JSON далее используется в проекте 4 (API) и проекте 5 (финальный веб‑сервис) как источник данных о вузах‑партнёрах.

## Как запускать скрапер

### 1. Разовый запуск (точка входа по ТЗ)

Из папки `project3-scraping`:

```bash
python run_scraper.py
```

Что произойдёт:

- Сработает `PostupiScraper`:
  - пройдётся по вузам из `config.UNIVERSITIES`;
  - соберёт данные по целевым направлениям;
  - допишет строки в `data/universities_raw.csv`;
  - обновит агрегированный `data/partners.json`.

- Сработает `OlympScraper`:
  - пройдётся по целевым олимпиадам;
  - соберёт льготы по нашим вузам;
  - допишет строки в `data/olympiads_raw.csv`;
  - допишет в секцию `olympiads` внутри `data/partners.json`.

### 2. Непрерывный режим (планировщик)

```bash
cd project3-scraping
python -m scheduler.runner
```

Поведение:

- Первый запуск скрапера — сразу.
- Затем каждые N часов (по умолчанию `schedule_interval_hours = 6` в `config.py`).
- В CSV добавляются новые строки с актуальным временем (`timestamp`).
- Актуальный срез данных всегда лежит в `data/partners.json`.

Для быстрой проверки можно временно поменять интервал в `config.SCRAPER_SETTINGS`:

```python
"schedule_interval_hours": 0.01  # ~36 секунд, только для отладки
```
