# School Admin System
Монорепозиторий системы управления профильной школой.
Разработан в рамках курса прикладного Python (МФТИ).

## Проекты
| Проект | Папка | Ветка | Статус |
|--------|-------|-------|--------|
| Project 1: CLI File Manager | `project1-cli/` | `dev` | ✅ Готов |
| Project 2: GUI (Flet) | `project2-gui/` | `feature/gui` | ✅ Готов |

## Требования
Python 3.10+
## Установка
```bash
pip install -r requirements.txt
```
## Запуск Project 1
```bash
cd project1-cli
python -m cli
```
## Запуск Project 2
```bash
cd project2-gui
python run_gui.py
```
