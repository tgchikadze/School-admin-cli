# School Admin System
Разработана для администрирования школы "Биотех 225", профильных биотехнологических классов школы 225.  Система частично реализует функционал предоставленного технического задания.
## Разработка модулей системы
Проект реализовался поэтапно от 1 к 5 проекту:

### Проект 1 (dev):
- Функционал управления хранимыми в системе файлами  (реализован в проекте 1), в т.ч.:
-    анализ директории (расчет общего размера, подсчет количества файлов и папок, детализация по расширениям)
-    поиск файлов по имени (подстрока, без учета регистра), по расширению
-    операции с файлами (копирование в существующую или новую директорию, обработка ошибок: нет файла, попытка скопировать директорию и т.п.)
- Функционал определения координат полей для автозаполнения любых бланков (в том. числе многостраничных)
- Функционал автозаполнения одной квитанции данными, указанными в json.

### Проект 2 (feature/gui):
- Создание, поддержание и редактирование json-БД учеников, классов, выбранных ЕГЭ
- Функционал одиночной и массовой генерации квитанций об оплате на основании данных о количестве спецкурсов, их базовой стоимости, задолженности по оплате с обеих сторон (поле - компенсация):
-   все записи json-БД;
-   фильтр по классам
-   по данным поиска.
- Поиск по json-БД (по ФИО, классу, номеру договора);
- Функционал выбора предметов ЕГЭ только для 11 класса и сохранение выбора в json-БД (результат выбора используется при расчете стоимости обучения при генерации квитанций)
Все указанные функции поддерживают выбор пользователем файлов с локального диска.

### Проект 3 (features/scraping):
Данный функционал осуществяется для завуча профильных классов для своевременного информатирования учеников 10 и 11 классов о льготах и курирования их участия.
- По заданному csv ссылок: cкрапинг/парсинг информации о приеме на профильные образовательные программы заданных вузов, создание структуры и автоматическое наполнение json-БД:
-   с https://postupi.online/ (класс PostupiScraper)
-   с официальных сайтов заданных вузов (класс OfficialSiteScraper)
- По заданному csv ссылок: cкрапинг/парсинг информации о профильных олимпиадах, дающих льготы в заданных вузах (класс OlimpiadsBenefitScraper)
- Запись RAW данных отдельно по вузам и олимпиадам
- Автоматическое структурирование данных в JSON
- Очистка данных скрайпинга
- Парсинг статического html и pdf документов (без Seleniun) динамические страницы парсятся частично
- Дополнения  csv ссылок на найденные релевантные pdf-документы
- Запуск скрайпинга по расписанию.
  
### Проект 4 (features/api):
- Создание 2-x .db из json-БД проекта 3: по вузам/направлениям подготовки и олимпиадам
- Pевю записей и редактирование БД по олимпиадам;
- Web-интерфейс с минимальным css;
- API- документация

### Проект 5 (features/final):
- Объединяет все БД в одну .db с усовершенствованым функционалом
- Реализует функции проектов 1-4 через Web-интерфейс + скрайпинг динамических страниц с помощью Selenium
- Функционал регистрации/авторизации на сайте с доступом, согласно роли
